====================================================================================================
                        SAFECHAT - BẢNG ĐẶC TẢ ID LAYOUT & HƯỚNG DẪN CODE DÀNH CHO AI VIBE
====================================================================================================
Mục đích: File này tổng hợp chi tiết tất cả các màn hình (layouts) của ứng dụng SafeChat, kèm theo:
- Tên file layout XML tương ứng
- Danh sách đầy đủ ID của các View, Type (kiểu View) và vai trò chức năng
- Sự kiện (Events) & Logic cần code (Binding, OnClickListener, TextWatcher, RecyclerView Adapters,...)
- Hướng dẫn điều hướng luồng màn hình (Navigation Flow) giúp AI vibe code cực nhanh và chính xác!

====================================================================================================
MỤC LỤC CÁC MÀN HÌNH & COMPONENT:
1.  cho.xml                     - Màn hình chờ / Khởi động (Splash Screen)
2.  dangnhap.xml                - Màn hình Đăng nhập (Sign In)
3.  dangky.xml                  - Màn hình Đăng ký tài khoản (Sign Up)
4.  chung.xml                   - Màn hình chính / Danh sách trò chuyện (Chats List / Home)
5.  item_chung.xml              - Item cuộc trò chuyện cho RecyclerView ở màn hình chung
6.  chat.xml                    - Màn hình Chat 1 - 1 (Direct Message)
7.  chat_group.xml              - Màn hình Chat Nhóm (Group Chat)
8.  item_message_sent.xml       - Item tin nhắn gửi đi (Sent Message Bubble)
9.  item_message_received.xml   - Item tin nhắn nhận được (Received Message Bubble)
10. friends.xml                 - Màn hình Bạn bè & Lời mời kết bạn (Friends & Requests)
11. item_friend.xml             - Item bạn bè cho RecyclerView ở màn hình friends
12. create_group.xml            - Màn hình Tạo nhóm chat mới (Create Group)
13. profile.xml                 - Màn hình Trang cá nhân & Đăng xuất (Profile / Account)
14. activity_main.xml           - Layout MainActivity mặc định

   chung.xml

      ├──> Click btnNewChat ("Trò chuyện mới") ────> create_group.xml (hoặc danh sách bạn)
